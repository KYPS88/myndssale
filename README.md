# Mynds — เว็บขายสินค้า (myndssale)

เว็บ e-commerce ของแบรนด์ **Mynds (มายด์)** — *Hot Weather Apparel* สร้างตาม requirement ในชีต
**“Website Brief - Mynds”** ใช้ Next.js 16 + SQLite (ไม่ต้องมี database server แยก) พร้อมระบบหลังบ้าน

## เริ่มใช้งาน

ต้องใช้ Node.js **22.13 ขึ้นไป** (ใช้ `node:sqlite` ที่มากับ Node)

```bash
npm install
cp .env.example .env        # แล้วตั้ง ADMIN_PASSWORD / SESSION_SECRET
npm run dev                 # http://localhost:3000  · หลังบ้าน /admin
```

ครั้งแรกที่เปิดเว็บ ระบบจะสร้างฐานข้อมูล `data/mynds.db` และนำเข้าสินค้าจาก `data/product-master.csv`
(export จากชีต 03_Product_Master — **ตัดคอลัมน์ต้นทุนออกแล้ว**) ให้อัตโนมัติ

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run dev` | เปิดโหมดพัฒนา |
| `npm run build && npm start` | build และรัน production |
| `npm test` | unit test (ราคา/คูปอง/ค่าส่ง, แปลงข้อมูลสินค้า, สร้างออเดอร์/ตัดสต็อก) |

## ข้อมูลสินค้าที่นำเข้า

- 58 รุ่น / 1,641 variant · **เปิดขาย 48 รุ่น**, ซ่อน 10 รุ่น (ของแถม และรุ่นที่ราคาในชีตเป็น 0 เช่น Daisy DSC, คาร์ดิแกน, Sunlight Shirt) — ตั้งราคาแล้วกดเปิดขายได้ในหลังบ้าน
- ชีตยังไม่ได้กรอก หมวดหมู่/เพศ/คอลเลกชันหลายแถว ระบบจึง**เดาจากชื่อสินค้า** (เช่น “โปโล” → เสื้อโปโล, “KIDS” → เด็ก) ถ้ากรอกในชีตแล้วจะใช้ค่าจากชีตแทน
- ไซซ์ถูกปรับให้ตรงกัน (`4Xl` → `4XL`), ชื่อสีรวมตัวพิมพ์เล็ก/ใหญ่ (`Black`/`BLACK`)
- รูปใช้ลิงก์เดิมจาก `jst-yikan-picspace...aliyuncs.com` ถ้าลิงก์ใช้ไม่ได้จะแสดงรูป placeholder แทน

## Deploy (แนะนำ Railway / VPS)

SQLite ต้องอยู่บนดิสก์ถาวร — **ห้ามใช้ Vercel/serverless** (ไฟล์ฐานข้อมูลจะหาย)

1. สร้าง service จาก repo นี้ · Build: `npm run build` · Start: `npm start`
2. เพิ่ม **Volume** เช่น mount ที่ `/data` แล้วตั้ง `DATABASE_PATH=/data/mynds.db`
3. ตั้ง env ตาม `.env.example` (`ADMIN_PASSWORD`, `SESSION_SECRET`, `NEXT_PUBLIC_SITE_URL=https://mynds.co`, GA/Pixel/LINE ถ้ามี)
4. ชี้โดเมน Mynds.com / Mynds.co มาที่ service (HTTPS อัตโนมัติ) · staging ตั้ง `NEXT_PUBLIC_NOINDEX=1`
5. Backup: สำรองไฟล์ `mynds.db` เป็นระยะ (เช่น `sqlite3 mynds.db ".backup backup.db"`)

## สิ่งที่ยังต้องการจากแบรนด์ (ชีตยังว่าง / ต้องตัดสินใจ)

1. **Payment gateway** (“ตัดบัตร พี่บอย”) — ต้องรู้ผู้ให้บริการ (เช่น Omise, 2C2P, GB Prime Pay, KBank) เพื่อเชื่อมตัดบัตรอัตโนมัติ ตอนนี้รองรับโอน/QR + COD
2. **เลขบัญชี / PromptPay ID** — ใส่ในหลังบ้าน → ตั้งค่าร้าน (ยังไม่ใส่ หน้าออเดอร์จะบอกว่าทีมงานจะส่งช่องทางชำระให้)
3. **ค่าส่ง/ส่งฟรี/COD/ตัดรอบ** — ตอนนี้ใช้ค่าเริ่มต้น ค่าส่ง ฿50, ส่งฟรี ฿990, COD +฿20, ตัดรอบ 14:00 (แก้ได้ในหลังบ้าน)
4. **นโยบายทั้งหมดเป็นร่าง** (`lib/policies.ts`) — ชีต 06 ระบุให้ผู้เชี่ยวชาญตรวจก่อนเปิดจริง โดยเฉพาะเงื่อนไขเปลี่ยน/คืน 7 วัน
5. **ตารางไซซ์** หน้า `/size-guide` เป็น**ค่าประมาณ** ต้องแทนด้วยตัวเลขจริง และใส่ “ตารางไซซ์ URL” รายรุ่นในชีต
6. **โลโก้/CI** — ลิงก์ Drive ในชีต 04 เข้าไม่ได้ ตอนนี้ใช้ตัวอักษร MYNDS · **Hero banner** desktop/mobile ยังไม่มีไฟล์
7. **ข้อความสินค้า** — คำอธิบาย วัสดุ วิธีดูแล จุดขาย SEO title ยังว่างทั้งหมด (กรอกในชีตแล้วนำเข้าใหม่ หรือแก้ในหลังบ้าน)
8. ประวัติแบรนด์, คีย์เวิร์ด SEO, GA4/Pixel ID, LINE Messaging API token
9. ยังไม่ได้ทำ (ชีตระบุ “เลือกตามโมเดล”/“แนะนำ”): บัญชีลูกค้า/สะสมแต้ม, รีวิวสินค้า, บทความ, ภาษาอังกฤษ, sync สต็อกกับระบบคลัง/POS, ส่งอีเมลยืนยันออเดอร์ (SMTP)
